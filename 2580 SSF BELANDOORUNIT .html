Data & Security

This starter stores information in the current browser only. It does not yet provide real login, cross-device sync, or server-side security.

To enable online sync and real login

  1. Create a Firebase project.
  2. Enable Firebase Authentication (email/password) and Cloud Firestore.
  3. Add your Firebase web configuration in the project files.
  4. Set Firestore security rules so only authorized admins can manage records and members can read permitted data.
  5. Deploy the web app and build the Android wrapper using the included README.
